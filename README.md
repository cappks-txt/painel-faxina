# Painel — Faxina do CRM

Acompanhamento público do app **Faxina do CRM**, do Desafio Vibecode Br24
(card 02/15): um app que encontra duplicados e cadastros com problema numa base
de CRM Bitrix24, para o time de suporte limpar sem apagar o que é certo.

**<https://cappks-txt.github.io/painel-faxina/>**

A página é **gerada**, não escrita: tarefas, branches, commits e contagem de
testes saem do repositório do app; requisitos e achados saem de um mapa
versionado junto do código. Painel escrito à mão mente na terceira tarefa.

O código do app fica em repositório próprio, privado até a entrega de 03/11,
como o desafio prevê. Aqui mora só a página de acompanhamento, sem dado de
cliente, sem credencial e sem informação interna de equipe.
